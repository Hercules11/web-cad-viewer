# Web CAD 查看器

纯前端 (零后端) 的 DWG 查看与轻量编辑工具: 浏览器直接打开本地 DWG 文件, 查看图纸、增删线条元素, 并支持**框选区域导出 SVG**。

## 快速开始

```bash
pnpm install
pnpm dev        # 开发服务器, 默认 http://localhost:5173
pnpm build      # 生产构建 (tsc + vite build)
```

> 需要 Node 20+, pnpm 8+。首次打开图纸前无需任何服务端, 文件不会上传。

## 功能

| 模块 | 说明 |
|---|---|
| **打开** | 拖拽 / 文件选择打开本地 `.dwg`(LibreDWG WASM 解析) / `.dxf`; 示例按钮加载测试图纸 |
| **查看** | 滚轮以光标为中心缩放、中键/右键拖拽平移、Zoom Extents; 模型空间/布局切换; 渐进加载 (解析在 Worker 中, 不卡界面) |
| **图层** | 图层面板: 显隐切换、颜色图例、实体计数; 当前绘制图层选择 |
| **主题** | 深色 / 浅色一键切换 (工具栏 ☾ 按钮): ACI 7 白/黑随背景自动反转 (同 TrueView 行为), 选择持久化 |
| **编辑** | 单击/框选 (左→右包含, 右→左相交, Shift 加选); 拖动所选直接移动; Delete 删除; 撤销/重做 (Ctrl+Z/Y) |
| **绘制** | 直线 / 多段线 / 圆 / 圆弧 / 矩形; 对象捕捉 (端点/中点/圆心/象限/最近点, 可开关) |
| **导出 SVG** | 工具栏"框选导出 SVG"→ 拖拽框选区域 → 弹窗设置精度/背景/隐藏图层 → 下载矢量 SVG |
| **导出 PNG** | 当前视图 2 倍分辨率截图 |

### SVG 导出说明

- 世界坐标直接映射为 SVG 用户单位 (Y 轴自动翻转), `vector-effect="non-scaling-stroke"` 保证线宽一致
- 块引用输出为 `<defs>` + `<use>` 引用 (含嵌套块), 文件体积小且可继续编辑
- 文字输出为 `<text>` (字体栈: 宋体/微软雅黑, 需查看机器有对应字体)
- 深色主题下解析的 ACI 7 (白) 导出时自动转黑, 适配白底
- 图案填充 (非 Solid) 以半透明填充近似

## 快捷键

`V` 选择 · `L` 直线 · `P` 多段线 · `C` 圆 · `A` 圆弧 · `R` 矩形 · `Del` 删除 · `Ctrl+Z/Y` 撤销/重做 · `Esc` 取消/清空选择 · 右键结束多段线

## 架构

```
src/
  core/       类型系统 (DXF 内核模型) · ACI 色表 · 几何离散 · 块展开 (worker/主线程共用)
  parse/      parser.worker.ts — LibreDWG WASM 解析 → 实体记录 + 烘焙几何批 (渐进回传)
  render/     three.js 合批渲染器 (按图层分组) · 文字图集 (canvas atlas)
  app/        文档模型 (flatbush 空间索引 + 动态编辑集) · 工具状态机 · 捕捉 · 撤销命令栈
  export/     SVG 导出器
  ui/         工具栏 / 图层面板 / 状态栏 / 对话框
public/wasm/  libredwg-web.wasm
```

数据流: `文件 → Worker 解析 → 实体记录(全量) + 烘焙批(Float32Array transferable) → WebGL 合批`
编辑: `工具状态机 → Command(do/undo) → 文档变更 → 静态批过滤 + 动态层重烘焙`

## 已知限制

- DWG **写回**暂未实现 (计划: 另存 DXF)
- 文字按系统字体近似渲染 (SHX 形字体未逐一还原), MTEXT 复杂排版 (堆叠/多列) 简化处理
- 图案填充 (ANSI31 等) 以半透明近似, 未绘制真实线型图案
- 外部引用 (XREF) / 图片 / OLE / 代理实体按忽略处理, 加载完成后会提示缺失清单
- 透明度: 实体/图层 alpha 已支持 (含 SVG 导出), 但缺少实际样例深度验证
- 超大图纸 (百万实体级) 未做分块优化, 当前目标为 10 万实体级 60fps
